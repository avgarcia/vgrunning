# UX-01 — Recorrido cognitivo sintético P03

**Estado:** Ejecutado como revisión experta — no es una prueba con participante

**Fecha:** 2026-08-30

**Perfil sintético:** Corredor activo acostumbrado a recibir planes mediante PDF o mensajería

**Superficie:** Referencia móvil

## Objetivo del perfil

Explorar el cambio desde un documento lineal o mensajes a una interfaz por días, sin asumir que el perfil busca PDF, chat o contacto con el entrenador.

## Tareas recorridas

| Tarea | Criterios | Evidencia objetiva | Pregunta cognitiva |
| --- | --- | --- | --- |
| `T-UX01-01` | `CA-UX01-01`, `CA-UX01-02` | `Mi plan` presenta la semana actual como destino inicial. | ¿Reconocerá la cuadrícula como su plan semanal? |
| `T-UX01-02` | `CA-UX01-03`, `CA-UX01-04` | Una tarjeta abre bloques, modalidad y ubicación. | ¿Descubrirá que debe abrir el día para ver detalle? |
| `T-UX01-03` | `CA-UX01-05`, `CA-UX01-06` | `Guardar` confirma explícitamente y `Cancelar` está separado. | ¿Comprenderá que el registro sustituye enviar un mensaje? |
| `T-UX01-04` | `CA-UX01-07` | El comentario aparece solo después de información y decisión. | ¿Entenderá que comentar no es obligatorio? |
| `T-UX01-05` | `CA-UX01-09` | El historial agrupa sesiones por semana y carga más. | ¿Preferirá esta agrupación a buscar mensajes antiguos? |
| `T-UX01-06` | `CA-UX01-08` | La retirada conserva el seguimiento estructurado. | ¿Distinguirá datos estructurados y texto libre? |
| `T-UX01-07` | `CA-UX01-12` | El cierre de sesión está en el menú personal. | ¿Encontrará el menú sin una navegación propia de mensajería? |

## Estados asignados

- `ES-UX01-08`: el mensaje dice únicamente `Este contenido no está disponible`; no atribuye causa ni propiedad.
- `ES-UX01-09`: el historial vacío explica que todavía no hay entrenamientos iniciados.
- `ES-UX01-02`: el acceso muestra un error genérico y permanece operativo para reintentar.

## Hipótesis pendientes

- puede esperar descargar o imprimir la semana;
- puede considerar que un comentario debe acompañar siempre al seguimiento;
- puede buscar confirmación de que otra persona ha recibido la información.

PDF, chat y notificaciones no se convierten en requisitos de UX-01.

## Resultado

Recorrido técnico completado. La transición mental desde PDF o mensajería requiere evidencia de beta.
